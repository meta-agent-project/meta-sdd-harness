# meta-interview

모호한 아이디어를 질문으로 구체화한다.
결과로 roadmap.md(무엇을 어떤 순서로)와 contract.md(프로젝트 규칙)를 만든다.

## 순서

1. 읽기
   roadmap.md, contract.md, backlog.md, issues.md를 읽는다.
   roadmap.md가 이미 있으면 새로 만들지 않고 고친다. 목표와 사용자가 바뀌는 큰 방향 전환만 여기서 한다.
   기능 하나의 추가, 삭제, 순서 변경은 /meta-requirement-change로 보낸다.

2. 의도 파악
   무엇을, 누구를 위해, 왜 만드는지 묻는다.
   한 번에 질문 하나. 답을 들으면 사용자가 한 말과 내 추측을 나눠서 다시 보여준다.

3. 모호함 점검
   네 영역을 명확, 부분, 모호로 판단한다.
   - 목표: 무엇이 되면 성공인가
   - 사용자: 누가 쓰고, 지금은 어떻게 해결하고 있나
   - 범위: 무엇을 하고 무엇을 하지 않나
   - 제약: 돈, 시간, 환경, 꼭 지킬 것
   모호한 영역부터 질문한다. 모두 명확해지면 다음으로 간다.
   질문은 최대 10개. 사용자가 "그만"이라고 하면 바로 다음으로 간다.

4. 모호한 말 다듬기
   "편하게", "빠르게", "스마트하게" 같은 말이 나오면 확인할 수 있게 정의해 달라고 한다.
   예: "빠르게"는 몇 초 안인가

5. 전제 확인
   지금까지 들은 내용에서 전제 3~5개를 문장으로 뽑아 동의를 받는다.
   예: "사용자는 혼자 쓴다. 여러 명이 함께 쓰지 않는다"
   동의하지 않는 전제가 있으면 3번으로 돌아간다.

6. 이미 있는 것 찾기
   meta-researcher 에이전트에게 비슷한 앱, 오픈소스, 무료 서비스를 찾게 한다.
   그대로 쓸 수 있는 게 있으면 사용자에게 알린다.

7. 접근 고르기
   2~3개를 추천과 함께 제시한다.
   - 가장 작게: 가장 빨리 써 볼 수 있는 방법
   - 가장 바르게: 길게 봤을 때 좋은 방법
   - 다르게: 문제를 다른 각도에서 푸는 방법

8. 기술 정하기
   프로젝트 전체에 쓸 기술을 정한다. 언어, 프레임워크, 패키지 관리자, 저장소, 테스트 도구, 실행 환경.
   meta-researcher 에이전트로 후보의 최신 버전, 무료 여부, 유지보수 상태를 먼저 확인한다.
   항목마다 추천안을 첫 번째에 두고 하나씩 묻는다.
   기능 하나에만 쓰는 기술은 여기서 정하지 않는다. meta-tech가 정한다.
   JavaScript 프로젝트의 패키지 관리자는 pnpm을 추천안으로 둔다. 구현 레인마다 작업 폴더에 의존성을 빠르게 준비할 수 있기 때문이다.

9. 기능 나누기
   기능 하나가 spec 하나가 되게 나눈다. 기능 하나는 혼자 써 볼 수 있어야 한다.
   첫 기능은 가장 좁게 시작할 수 있는 것으로 고른다.
   지금 안 하는 것은 "나중에"로, 아예 안 하는 것은 "하지 않는 것"으로 옮긴다.
   기능에 번호를 붙이지 않는다. 번호는 meta-spec이 붙인다.

10. 초안 보여주기
   contract.md의 원칙과 제약이 모두 "이렇게 한다" 형태인지 먼저 확인한다.
   "하지 않는다"가 있으면 .claude/meta-rules.md의 "결과를 선언하고, 방법은 정하지 않는다"대로 바꾼다.
   roadmap.md와 contract.md 초안을 보여주고 확인받는다. 확인 전에는 저장하지 않는다.

11. 마무리
   저장하고 커밋한다. 커밋 메시지: "docs: 로드맵과 프로젝트 규칙"
   첫 기능을 /meta-spec으로 시작하라고 알린다.

## roadmap.md 형식

```
# 로드맵

목표
강사가 수업 자료를 한 곳에서 만들고 안전하게 보관한다.

사용자
- 혼자 수업을 준비하는 강사
- 지금은 폴더와 파일 이름으로 직접 관리한다

성공 기준
- 새 강의를 30초 안에 만들 수 있다
- 3개월 동안 강의를 잃어버린 적이 없다

기능 순서
1. lecture-store 강의 저장: 강의를 만들고 안전하게 저장한다
2. slide-editor 슬라이드 편집: 강의 안에서 슬라이드를 만든다
3. export 내보내기: 강의를 PDF로 내보낸다

나중에
- 여러 기기 동기화

하지 않는 것
- 여러 명이 함께 편집
- 수강생용 화면
```

## contract.md 형식

```
# 프로젝트 규칙

원칙
- 사용자 데이터는 어떤 경우에도 보존된다
- 인터넷이 없어도 동작한다

제약
- 무료 서비스만 쓴다
- Windows와 macOS에서 동작한다

기술
- 언어: TypeScript
- 프레임워크: Next.js 15
- 패키지 관리자: pnpm
- 저장소: Supabase Postgres
- 테스트: Vitest, Playwright, MSW
- 실행 환경: 브라우저, Vercel

품질 기준
- 누르거나 입력하면 0.1초 안에 화면이 반응한다
- 저장, 조회 같은 일반 동작은 0.5초 안에 끝난다
```
